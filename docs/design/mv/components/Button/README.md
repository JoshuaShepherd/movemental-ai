# Button

The one primary action on a page: an ink pill, white 16px Geist at weight 500, 52px tall, 28px side padding, `radius-pill`.

- One per page or panel. Everything beside it is a **TextLink**.
- Use a real `<a href>` when it navigates and a `<button type="button">` when it acts. Never a styled div.
- Labels are verbs the person would say: "Write your Resolution", "Send invitations", "Bring this to your working group".
- A reassurance line can sit under it in `ui-s` graphite ("About four minutes. No account.").
- In a side column, the button runs full width.
