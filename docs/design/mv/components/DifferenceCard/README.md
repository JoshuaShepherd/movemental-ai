# DifferenceCard

A pair of opposing statements side by side, each in a plain bordered box with its count, under the theme name, followed by a disclosure: "What's at stake, and two questions for the working group".

- Neither side is styled as the better one. Equal boxes, equal weight, no accent.
- The disclosure explains both positions charitably, then poses two questions in the `question` style.
- Stacks to one column below 700px.
