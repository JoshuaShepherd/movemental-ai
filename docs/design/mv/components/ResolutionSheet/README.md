# ResolutionSheet

The Resolution as a document: `sheet` paper, a `rule` border, `radius-sheet` corners, 64px by 72px padding on desktop and 32px by 22px on a phone.

Order, top to bottom: a graphite kicker ("My Resolution for [organization]"), the `sheet-title` line "Resolved, that [organization] should…", one row per theme from the starred statement (theme label in `caption` graphite, statement in `statement`), then "Hardest for us to adopt today", "What I'll do", an optional "If I had two minutes", a signature rule with the person's name, and the date.

- Rows stack label-over-statement below 700px.
- The sheet prints as it looks; everything around it is `noprint`.
- The same sheet renders the shared view at `/r/[id]`, with the date line reading "Updated [date]" after an amendment.
