# TextLink

Every action that is not the primary one: underlined 15px Geist with a 4px underline offset, at least `target-min` (44px) tall so it is easy to hit.

- Ink by default; graphite when it should recede (header utilities like "Save and leave").
- Use `<button>` for actions and `<a href>` for navigation, styled identically.
- Stack several with a 2px gap; each one keeps its own 44px row.
