# ThresholdNote

What any grouped view shows before five people have written theirs: five small marks (filled for each Resolution written, outlined for the rest) and one sentence saying how many and what happens at five.

- The threshold is five everywhere a group's choices are combined. Below it, no statement, count or role is shown.
- Above it, the note gives way to the **CountRow** and **DifferenceCard** views.
- The marks are decorative (`aria-hidden`); the sentence carries the meaning.
