How the network grows

The network grows by invitation. Each person in it was asked by someone already here, who was willing to stake their own name on them. There is no application. If you’ve been invited, you’ll have a link.

It is capped at about one hundred leaders, so that everyone in it can still be known by the others.

What an invitation looks for

  • A real body of work
  • Leadership that multiplies
  • Movemental DNA, named or not
  • Conduct the network can vouch for

Leaders nominate. Objections are written. Admission is by consent.
