images.** They are captured by re-rendering the DOM, which means web fonts fall
back and some images do not embed. Use them for orientation; read the markup
when a value matters.

## Home history

`designs/history/` holds home v2, v3, and the original. They are shipped so the
v4 decisions are legible in context — what the hero looked like before, and why
the leader band changed. **They are not build targets** (L-5).
